# Problemas comuns

**Nada é bloqueado.**
Abra o painel: o *Status* deve dizer "Ativa nesta aba" ou "Pronta para instagram.com". Se disser *Sem acesso ao site*, toque em **Permitir acesso ao instagram.com**. Se disser *Recarregue a aba*, atualize o Instagram (a extensão foi instalada ou atualizada com a aba aberta).

**O bloqueador está pausado.**
No modo Automático e no Foco, pausas terminam sozinhas no horário mostrado. "Retomar agora" volta na hora.

**Algo escapou (um Reel, um sugerido).**
O Instagram pode ter mudado a interface. Veja [selectors.md](selectors.md) para diagnosticar e abra uma issue com o que apareceu (sem prints de conversas privadas).

**Um vídeo comum de um amigo sumiu.**
Provavelmente o Instagram o publica como Reel. Desligue *Vídeos curtos* se preferir ver Reels de quem você segue no feed.

**Quero ver o Explorar.**
Bloqueios → desligue *Ocultar Explorar*. Os Reels continuam trocados por aviso se *Vídeos curtos* estiver ligado.

**Modo Foco: como saio?**
Painel → Pausar (ou Modo) → *Começar a espera* → depois de 1 minuto digite `quero desativar agora`. Você terá 5 minutos para mudar o que quiser. Também é sempre possível remover a extensão pelo navegador.

**Firefox: a extensão some ao fechar.**
Carregamento temporário é assim. Para manter, instale a versão assinada (ver [publishing.md](publishing.md)).

**Safari: não aparece na lista de extensões.**
Abra o app Instagram Minimal uma vez. Em builds de desenvolvimento no Mac, permita extensões não assinadas no menu Desenvolvedor.
