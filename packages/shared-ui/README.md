# @im/ui

Design system e telas em React: boas-vindas, escolha de modo, painel, bloqueios, privacidade e desbloqueio do modo Foco. Usado no popup, na página de opções e no site.

Tokens em `ui.css`: `#FFFFFF`, `#F5F5F7`, `#86868B`, `#1C1C1E`, `#007AFF`, fonte do sistema (SF Pro no ecossistema Apple, Segoe UI/Roboto nos demais), modo escuro automático.
